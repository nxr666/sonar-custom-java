Catching a broad Exception without logging its stack trace makes production failures hard to diagnose. Logging only e.getMessage() loses the call stack and root context.

Noncompliant Code Example

try {
  process();
} catch (Exception e) {
  log.error("process failed: {}", e.getMessage()); // Noncompliant
}

Compliant Solution

try {
  process();
} catch (Exception e) {
  log.error("process failed", e); // stack trace is logged
}
