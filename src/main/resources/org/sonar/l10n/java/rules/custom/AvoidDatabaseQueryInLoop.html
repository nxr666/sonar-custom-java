Executing database queries inside loops often leads to the N+1 query problem, where a query is executed once to fetch a list of items and then executed again for each item in the list. This increases latency and load on the database.

Noncompliant Code Example

for (User user : users) {
  // Each iteration triggers a database call
  orderRepository.findByUserId(user.getId());
}

Compliant Solution

List<Long> userIds = users.stream().map(User::getId).toList();
Map<Long, List<Order>> ordersByUser = orderRepository.findByUserIdIn(userIds)
  .stream()
  .collect(groupingBy(Order::getUserId));

for (User user : users) {
  List<Order> orders = ordersByUser.getOrDefault(user.getId(), List.of());
  // use orders
}
