Calling a @Transactional method from within the same class bypasses the Spring proxy, so transaction advice may not run.

Noncompliant Code Example

@Transactional
public void saveInTx() { ... }

public void create() {
  this.saveInTx(); // self-invocation bypasses proxy
}

Compliant Solution

@Transactional
public void saveInTx() { ... }

// call saveInTx() through another Spring bean (proxy boundary)
