In @Transactional methods, swallowing exceptions in a catch block without rethrowing or marking rollback-only can cause partial commits and inconsistent data.

Noncompliant Code Example

@Transactional
public boolean createOrder() {
  try {
    orderMapper.insert(order);
    return true;
  } catch (Exception e) {
    log.warn("failed: {}", e.getMessage());
    return true; // Noncompliant (exception swallowed)
  }
}

Compliant Solution

@Transactional
public boolean createOrder() {
  try {
    orderMapper.insert(order);
    return true;
  } catch (Exception e) {
    throw e;
  }
}
