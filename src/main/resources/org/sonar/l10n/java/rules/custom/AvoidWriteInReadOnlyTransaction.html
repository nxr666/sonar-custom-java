Methods marked with @Transactional(readOnly = true) should not perform data-modifying operations. Write calls in read-only transactions can cause inconsistent behavior and transaction misuse.

Noncompliant Code Example

@Transactional(readOnly = true)
public void syncData() {
  userMapper.updateById(user); // Noncompliant
}

Compliant Solution

@Transactional(readOnly = true)
public User loadUser(Long id) {
  return userMapper.selectById(id);
}
