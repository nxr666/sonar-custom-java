Transaction context in Spring does not automatically propagate to new threads or async task bodies. Write operations inside those async boundaries may execute outside the current transaction.

Noncompliant Code Example

@Transactional
public void createOrder() {
  executor.submit(() -> orderMapper.insert(order)); // Noncompliant
}

Compliant Solution

@Transactional
public void createOrder() {
  orderMapper.insert(order);
}
