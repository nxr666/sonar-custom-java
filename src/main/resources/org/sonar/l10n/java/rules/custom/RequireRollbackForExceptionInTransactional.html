In Spring, @Transactional may not rollback for checked exceptions by default. To avoid unexpected commits, configure rollbackFor = Exception.class (or stricter) explicitly.

Noncompliant Code Example

@Transactional // Noncompliant
public void createOrder() throws Exception {
  // business logic
}

Compliant Solution

@Transactional(rollbackFor = Exception.class)
public void createOrder() throws Exception {
  // business logic
}
