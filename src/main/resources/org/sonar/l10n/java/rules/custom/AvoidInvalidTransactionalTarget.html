Some @Transactional targets are ineffective with proxy-based AOP and can lead to missing transaction boundaries.

Risky Patterns

  • @Transactional on private or static methods
  • @Transactional on final classes or final methods

Noncompliant Code Example

@Transactional
private void saveInTx() { ... } // ineffective

@Transactional
public final void updateInTx() { ... } // risky

Compliant Solution

@Transactional
public void saveInTx() { ... }
