Calling remote APIs (HTTP/Feign/WebClient, etc.) inside loops can create N+1 network requests, causing high latency, timeout risk, and pressure on downstream services.

Noncompliant Code Example

for (User user : users) {
  remoteClient.getProfile(user.getId());
}

Compliant Solution

List<String> userIds = users.stream().map(User::getId).toList();
Map<String, Profile> profileMap = remoteClient.batchGetProfiles(userIds);
for (User user : users) {
  Profile profile = profileMap.get(user.getId());
  // use profile
}
