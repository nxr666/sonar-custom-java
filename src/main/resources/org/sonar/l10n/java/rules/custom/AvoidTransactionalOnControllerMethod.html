Controller methods should orchestrate request/response flow, while transaction boundaries should be owned by Service-layer methods. Putting @Transactional on Controller methods couples web and transaction concerns.

Noncompliant Code Example

@RestController
class OrderController {
  @Transactional
  public String create() { ... }
}

Compliant Solution

@RestController
class OrderController {
  public String create() {
    orderService.create();
    return "ok";
  }
}

@Service
class OrderService {
  @Transactional
  public void create() { ... }
}
