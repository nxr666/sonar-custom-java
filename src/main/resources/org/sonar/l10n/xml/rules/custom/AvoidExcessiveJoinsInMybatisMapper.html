SQL with too many JOINs is difficult to understand and often expensive to execute. In MyBatis mapper XML, excessive joins also make migration and tuning more fragile.

Noncompliant Code Example

<select id="queryUsers" resultType="User">
  SELECT u.id
  FROM users u
  JOIN dept d ON d.id = u.dept_id
  LEFT JOIN org o ON o.id = d.org_id
  INNER JOIN tenant t ON t.id = o.tenant_id
</select>

Compliant Solution

<select id="queryUsers" resultType="User">
  SELECT u.id, d.name
  FROM users u
  LEFT JOIN dept d ON d.id = u.dept_id
</select>
