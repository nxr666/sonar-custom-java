Using SELECT * (or SELECT DISTINCT *) in MyBatis mapper SQL makes result mappings fragile: column order changes, unused columns increase I/O, and schema changes can break consumers silently.

Noncompliant Code Example

<select id="findUser" resultType="User">
  SELECT * FROM users WHERE id = #{id}
</select>

Compliant Solution

<select id="findUser" resultType="User">
  SELECT id, name, email FROM users WHERE id = #{id}
</select>
