Using 1=1 as a placeholder predicate makes SQL harder to read and can hide condition-construction issues. In MyBatis mapper XML, prefer explicit dynamic conditions without tautological clauses.

Noncompliant Code Example

<select id="queryUsers" resultType="User">
  SELECT id, name FROM users WHERE 1=1
</select>

Compliant Solution

<select id="queryUsers" resultType="User">
  SELECT id, name FROM users
  
    AND id = #{id}
  
</select>
