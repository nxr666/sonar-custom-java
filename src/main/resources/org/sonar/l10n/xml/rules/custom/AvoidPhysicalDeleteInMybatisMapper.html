Physical delete (DELETE FROM ...) can permanently remove business data and makes data recovery/audit harder. In most business scenarios, prefer logical delete (for example, updating a deleted flag and keeping history).

Noncompliant Code Example

<delete id="removeUserById">
  DELETE FROM users WHERE id = #{id}
</delete>

Compliant Solution

<update id="removeUserById">
  UPDATE users SET deleted = 1, deleted_time = NOW() WHERE id = #{id}
</update>
