Executing UPDATE or DELETE without a WHERE condition may affect all rows in a table, causing severe data corruption or loss.

Noncompliant Code Example

<update id="disableUsers">
  UPDATE users SET enabled = 0
</update>

<delete id="clearOrders">
  DELETE FROM orders
</delete>

Compliant Solution

<update id="disableUsers">
  UPDATE users SET enabled = 0 WHERE tenant_id = #{tenantId}
</update>

<delete id="clearOrders">
  DELETE FROM orders WHERE tenant_id = #{tenantId}
</delete>
