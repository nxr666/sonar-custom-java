Deeply nested subqueries make SQL hard to reason about and tune. In mapper XML, prefer flattening query structure or splitting logic into simpler queries.

Noncompliant Code Example

<select id="queryUsers" resultType="User">
  SELECT *
  FROM users u
  WHERE u.id IN (
    SELECT user_id FROM orders
    WHERE product_id IN (
      SELECT id FROM products WHERE deleted = 0
    )
  )
</select>

Compliant Solution

<select id="queryUsers" resultType="User">
  SELECT u.id
  FROM users u
  WHERE u.id IN (SELECT user_id FROM orders)
</select>
