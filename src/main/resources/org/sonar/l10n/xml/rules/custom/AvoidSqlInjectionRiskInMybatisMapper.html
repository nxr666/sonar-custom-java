Using ${...} in MyBatis mapper SQL performs direct string substitution and can introduce SQL injection risk. Prefer #{...} parameter binding so values are passed safely as prepared-statement parameters.

Noncompliant Code Example

<select id="queryUsers" resultType="User">
  SELECT id, name FROM users WHERE name = ${name}
</select>

Compliant Solution

<select id="queryUsers" resultType="User">
  SELECT id, name FROM users WHERE name = #{name}
</select>

If dynamic identifiers (for example column names in ORDER BY) are unavoidable, use strict server-side allowlists before interpolation.
